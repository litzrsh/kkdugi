# ADR-0001: 관리자 UI 기술 및 라이트 디자인 기반

- 날짜: 2026-09-15
- 상태: 설계 채택, 구현 미착수
- 관련: 기존 저장소 ADR-0009의 프론트엔드 TODO를 이번 디자인 범위에서 구체화
- 후속 구체화: [ADR-0004](0004-thymeleaf-vue-sfc-runtime.md)의 공통 shell + SFC 런타임을 적용한다.

## 배경

장시간 조회·편집하는 관리 화면이다. 모던·심플·미니멀리즘·머테리얼을 지향하며 라이트 모드가 기본이다. 사용자 지정 스택은 Spring Thymeleaf + Vue, CSS3/vanilla JS, Bulma, Pretendard, line-awesome, AG Grid, Spring message다.

## 결정

1. Thymeleaf는 공통 shell·페이지 접근·초기 로케일 및 메시지 주입을 담당한다. Vue는 페이지 단위 편집 상태·검색·팝업을 담당한다. SPA 라우터와 별도 UI 프레임워크를 전제로 하지 않는다.
2. Bulma를 폼·버튼·레이아웃 기반으로 사용하고 별도 토큰 CSS로 관리자 디자인을 적용한다. Vue 관리 DOM을 vanilla JS로 중복 변경하지 않는다. AG Grid 컨테이너 내부는 Grid API가 관리한다.
3. Pretendard와 line-awesome를 로컬 정적 자산으로 제공한다. 라이브러리는 검증 후 버전을 고정한다. 운영 중 외부 CDN 의존을 기본값으로 두지 않는다.
4. 회백색 배경, 밝은 표면, 절제된 청록 강조색, 얕은 그림자·명확한 경계로 구성한다. Material의 계층·상태·피드백 원칙을 사용하며 Material UI 라이브러리를 추가한다는 의미는 아니다.
5. 시스템 고정 5개 메뉴를 먼저 설계한다. 프로젝트·agent 화면은 별도 요구 정의 후 확장한다.

## 대안과 결과

- 전면 SPA: 현재 Spring 페이지·메시지 체계와의 통합 범위를 불필요하게 넓혀 제외한다.
- 순수 Thymeleaf 폼: 배치 편집·다중 팝업 상태 처리가 복잡해 페이지 단위 Vue를 사용한다.
- Bulma 기본 스타일만 사용: 그리드와 폼의 시각 일관성을 위해 토큰 계층을 추가한다.
- 기존 ADR-0009의 Custom CSS 전제는 이번 사용자 지정 Bulma + Custom CSS로 구체화한다. 백엔드 구현은 변경하지 않는다.

## 검증 기준

한 화면에서 한국어·영어 레이블, 키보드 조작, 그리드와 팝업, 장문 메시지가 같은 디자인 기준으로 동작해야 한다. 실제 브라우저 검증은 후속 구현 단계다.
