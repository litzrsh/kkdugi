# ADR 0007: 로그인 완료 전 필수 인증 단계

- 날짜: 2026-09-17
- 상태: UI 구현 완료 / 서버 계약 제안

## 결정

로그인 화면과 같은 plain HTML + CSS3 + vanilla JS 구성으로 필수 비밀번호 변경 및 중복 로그인 확인 화면을 제공한다. Vue와 관리자 DialogHost는 사용하지 않는다. Spring은 검증된 로그인 진행 상태에 맞는 Thymeleaf 뷰를 렌더링하고 각 form POST를 처리한다.

최초·만료 비밀번호는 새 비밀번호 및 확인 입력을 완료해야 다음 단계로 진행한다. 다른 기기의 세션이 있으면 이전 세션 종료 후 로그인 또는 이번 로그인 취소를 명시적으로 선택한다. 기존 세션은 취소 시 유지한다.

동시 발생은 비밀번호 변경 후 중복 확인 순서를 미리보기 기준으로 사용한다. 인증 완료 전에는 관리자 접근을 허용하지 않는 것이 서버의 필수 조건이다. 서버가 발급·검증하는 일회성 challengeId 및 CSRF 토큰으로 각각의 POST를 연결한다. 브라우저의 쿼리/숨김 값은 권한 판정 근거가 아니다.

## 범위

퍼블리싱은 화면, 입력 검증, 일반 form POST 연동 지점을 제공한다. 비밀번호 정책 검증·저장, challenge 만료/재사용 방지, 기존 세션 종료와 신규 세션 발급은 서버 구현 사항이다. 현재 관리자 API 명세에는 인증 계약이 없어 endpoint를 임의로 확정하지 않았다.

자세한 모델 및 미리보기 시나리오는 [로그인 퍼블리싱 계획](../plan/07-login-publishing.md)을 따른다.
