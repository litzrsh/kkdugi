# 작업 계획 및 인수 기준

> 2026-09-16: API 계약과 실제 퍼블리싱 구조는 [ADR-0006](../adr/0006-admin-api-contract-and-publishing.md) 및 계획 06의 현재 상태를 우선합니다. 아래 내용은 최초 설계 기록입니다.

- 작성일: 2026-09-15
- 이번 실행 범위: 문서화만. 아래 P1~P6는 향후 작업 계획이며 현재 착수하지 않는다.

## 1. 단계

| 단계 | 선행 | 산출물 | 완료 기준 | 현재 상태 |
|---|---|---|---|---|
| P0 요구·설계 문서 | 사용자 요구·기존 코드·Kluvo 분석 | README, ADR 5건, 계획 문서 5건 | 5개 메뉴·연동·통합 dialog·모바일 추적 가능 | 작성·확장 완료 |
| P1 계약·자산 확정 | P0 | 라이브러리 버전/라이선스 목록, API/필드 매핑, 미확정 정책 결정 | Vue/Bulma/SFC loader 확보, bootstrap·grouped 메시지 조회·등록 언어 계약 확정 | 미착수 |
| P1.1 런타임 기술 검증 | P1 | 최소 SFC + 통합 Vue DialogHost + Grid 검증 결과 | 단일 Vue, 로컬 로드, CSP, Spring 템플릿, mount/dispose, `.mjs`, 모바일 dialog 통과 | 미착수 |
| P2 공통 디자인 검증 | P1.1 | 데스크톱·모바일 공통 shell·폼·그리드·팝업 시안 | 라이트 토큰, 장문, 터치·키보드, 전체 화면 편집 확인 | 미착수 |
| P3 공통 퍼블리싱 | P2 | Thymeleaf fragments, Vue 페이지 기반, 로컬 assets, 공통 상태 | 라이브러리 로드·메시지 주입·Grid 생명주기·변경 보호 | 미착수 |
| P4 화면 퍼블리싱 | P3 | admcode→admmsge→admmenu→admauth→aduser | 화면 명세의 정상·실패 상태를 fixture로 재현 | 미착수 |
| P5 실제 연동 | P4 + 백엔드 계약/구현 | 조회·저장·매핑 API 연결 | 실제 페이징·트랜잭션·오류·권한 계약 검증 | 미착수 |
| P6 인수 검수 | P5 | 검수표, 결함 수정, 실행 안내 | 아래 인수 기준 통과, 미구현 항목 명시 | 미착수 |

일정·담당자·공수는 API 준비 상태를 확인한 뒤 산정한다. 백엔드 확장은 디자인 작업의 숨은 완료 조건으로 두지 않고 의존 작업으로 관리한다.

## 2. 구현 전 결정 목록

| ID | 결정 필요 | 초기 제안 / 영향 |
|---|---|---|
| Q01 | 기본 메뉴 불변 범위 | 코드·구조·유형·노출 보호, 번역 편집 허용 / 메뉴 CRUD |
| Q02 | 코드 삭제 및 키 범위 | 하위 있으면 삭제 차단, 부모 내 코드 유일 / 코드 저장 |
| Q03 | 메시지 코드 밑줄 규칙 | 현재 Java 검증 유지 / 입력 검증 |
| Q04 | grouped 조회 및 언어 목록 | 코드 기준 페이징 + 전체 언어 / 메시지 화면 필수 의존 |
| Q05 | 번역 빈값·삭제·코드 삭제 경쟁상태 | 빈값 금지, 명시적 DELETE, 서버 대상 재검증 / 데이터 손실 방지 |
| Q06 | 권한 기본정보 저장·매핑 의미 | 기본정보 배치 제안, 매핑 독립 저장·메뉴 접근 권한 / 팝업 경계 |
| Q07 | 사용자 상태·초기화·연관 삭제 정책 | 서버 상태 목록, 초기화 전달 방식 미정 / 사용자 행동 |
| Q08 | 자기 계정·마지막 관리자 보호 | 서버에서 정책 결정·검증 / 잠금 사고 방지 |
| Q09 | Vue/Bulma 및 AG Grid 버전·라이선스 | 로컬 제공 및 버전 고정 / 퍼블리싱 착수 |
| Q10 | 길이·필수·검색·오류 코드·시간대 | DB/API 규칙을 문서와 맞춤 / 검증·다국어 |
| Q11 | 권한/사용자 생성·삭제 확장 범위 | 사용자가 명시하지 않은 기능은 확정 후 추가 / 범위 관리 |
| Q12 | SFC loader·CSP·단일 런타임 | 로컬 후보 검증 후 버전 고정, 불충족 시 사전 컴파일 대안 / P1.1 |
| Q13 | Page bootstrap·PageHandle·Dialog 계약 | ADR-0004 및 계획 04 기준 / 서버 초기화와 화면 해제 |
| Q14 | 모바일 지원 브라우저·검수 환경 | iOS Safari·Android Chrome 확인 환경 확보 / 가상 키보드·터치·viewport |

이 항목들은 문서화의 차단 사유가 아니다. 현재 코드로 지원되지 않는 계약을 구현 완료로 표시하지 않는다.

## 3. 후속 인수 시나리오

| 영역 | 필수 확인 |
|---|---|
| 공통 | 5개 메뉴 코드 일치, 현재 메뉴 표시, 미저장 이동 보호, 검색 초기화, 0건·로딩·실패·성공 |
| 배치 | 추가→수정→삭제 정규화, 기존 삭제 복원, 저장 중복 방지, 한 행 실패 전체 보존·롤백 |
| 공통코드 | 3레벨 왕복, 경로·코드·코드명 검색, 레벨별 페이징, 중복·하위 삭제 |
| 메시지 | 3언어 이상·2페이지 이상, 코드 단위 총건수, 언어 누락 없음, 셀↔flat 오류 매핑, 코드 규칙 |
| 메뉴 | 펼침/접힘 없는 트리, locale 팝업, 하위 포함 삭제·복원, 기본 보호, 순환 금지 |
| 권한 | 메뉴·사용자 매핑 조회/변경/취소/실패, 다른 페이지 기존 매핑 보존 |
| 사용자 | 기본정보·권한 수정, 비밀번호 초기화, 영구 삭제, 상태 일괄 변경의 취소·실패·성공 |
| 다국어 | SSR/Vue/Grid/오류 문구, 언어 전환 변경 보호, 긴 영문·누락 번역 |
| 접근성·화면 | 키보드, 초점, 레이블, 대비 측정, 200% 확대, 390~1920px, 장문과 가로 스크롤 |
| 실제 연동 | API 권한 거부, 세션 만료, 네트워크 유실, 재조회, 동시 변경 정책 |
| Vue 통합 | 단일 런타임, initData 직렬화, 팝업 주입, 화면 종료 시 unmount/Grid destroy, 로딩 경쟁·재시도 |
| 정적 배포 | 인터넷 차단, contextPath, assetVersion·의존 파일 일치, CSP, 중복 CSS·JS 로드 없음 |
| 통합 Dialog | Vue shell·본문 단일화, 호출 큐·자식 확인, 결과/취소/실패 구분, owner 정리·초점 복원 |
| 모바일 | 320~390px 필수 작업, 터치 44px, 전체 화면 편집, 가로 회전·가상 키보드, 5개 화면 필드 접근 |

브라우저·통합 검증은 구현이 있을 때 실행한다. 문서만 작성한 이번 작업에서 화면 테스트 통과나 서버 동작 확인을 주장하지 않는다.
