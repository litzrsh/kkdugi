# 메뉴관리 완료 및 검증

- 일자: 2026-09-19
- 화면: templates/pragma/admin/menu.vue → 공통 BatchPage
- API: GET /api/v1.0/admin/menu, POST /api/v1.0/admin/menu/persist

## 완료 범위

- 전체 트리를 펼쳐 표시하고 그룹·화면 아이콘, 깊이, 사용 여부·닫기 허용 상태를 표시한다.
- 루트 등록, 저장된 부모 아래 하위 등록, 수정, 하위 일괄 삭제, 복원, 배치 저장을 지원한다.
- 언어별 라벨·설명은 탭으로 편집한다. 현재 언어의 라벨이 없으면 다른 번역·프로그램·ID 순으로 표시한다.
- 메뉴 검색은 현재 목록에서 수행하며 미저장 편집을 유지한다. 검색 결과에 상위 메뉴도 포함한다. 초기화는 전체 목록으로 복귀한다.
- 자식 삭제 후 부모 삭제처럼 겹치는 삭제를 하나의 하위 트리 복원 그룹으로 정리한다. 서버에는 삭제할 최상위 메뉴만 전달한다.
- 프로그램 경로는 Pragma와 동일하게 영문·숫자·밑줄·하이픈 및 폴더 구분자만 허용한다. 빈 프로그램은 그룹이다.
- 기본 관리 프로그램과 해당 메뉴를 포함한 상위 메뉴는 삭제·구조 변경을 UI와 서버 양쪽에서 차단한다. 라벨·설명 번역은 수정 가능하다.
- 로딩·저장 중에는 화면 편집을 차단한다. 저장 실패의 재시도는 조회로 초안을 덮어쓰지 않고 저장을 재시도한다.
- 메뉴 건수는 현재 편집 중인 목록을 반영한다. 모바일 팝업은 화면 폭 안에서 본문 스크롤과 고정 하단 버튼을 사용한다.

## 서버 계약 보완

기본 프로그램: admin/code, admin/message, admin/menu, admin/authority, admin/user.
기본 메뉴와 그 상위 메뉴의 program/icon/sort/use/close 구조 변경 또는 삭제는 409 menu.err.immutable이다. parentId는 모든 기존 메뉴에서 변경할 수 없다.
잘못된 program, Y/N 외 use·close, 음수 sort는 400 menu.err.malformed_request다.

## 검증 결과

- Maven 149개 테스트 통과: 실제 메뉴 등록·다국어 수정·use/close 변경·하위 삭제, 기본 메뉴 보호, 프로그램 검증 포함.
- JavaScript 29개 테스트 통과: 겹치는 삭제 복원, 번역 대체 표시, 검색·편집 보존, 삭제 요청 정규화 및 기존 화면 회귀 검사 포함.
- 실제 Spring 렌더링 SFC + HTTP fixture로 Edge 데스크톱 1440×1000, 모바일 390×844 검증. 코드·메시지 회귀, 메뉴 하위 등록, 잘못된 경로, 미저장 검색, 409 저장 실패와 재시도, 삭제·복원, 기본 메뉴 보호, 모바일 탭·textarea 확인.
- 브라우저 시험용 서버와 브라우저는 종료했다. 서버 DB 검증은 Spring 통합 테스트로 수행했으며 실제 사용자 메뉴는 수정하지 않았다.

메뉴 저장 결과는 관리 목록에서 재조회한다. 탐색 메뉴는 현재 서버의 로그인 세션 스냅샷이므로 재로그인 후 갱신된다는 기존 안내를 유지한다. 아직 없는 home/권한관리/사용자관리 화면의 구현은 이 작업 범위에 포함하지 않는다.
