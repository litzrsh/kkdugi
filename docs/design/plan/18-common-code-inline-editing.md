# 공통코드 그리드 편집 개선

2026-09-19

## 편집 방식

| 항목 | 동작 |
|---|---|
| 신규 코드 | 새로 등록 시 그리드에 행을 추가하고 코드 input에 포커스. 신규 행에서만 편집 가능 |
| 저장된 코드 | 잠금 유지. 서버의 코드·계층 경로 불변 계약을 유지하기로 사용자 확인 |
| 사용 여부 | 셀 클릭 후 Y/N을 표시 언어의 사용/미사용으로 선택 |
| 정렬순번 | 셀 클릭 후 number input. 0 이상의 정수, 빈 값은 저장 거부 |
| 코드명·설명 | 현재 언어의 이름·설명을 요약 표시. 행 버튼으로 언어별 탭 팝업 편집 |
| 확장값 | 입력된 값 개수 표시. 행 버튼으로 1~5 탭의 고정 높이 textarea 팝업 편집 |
| 상태·작업 | 코드·메시지·메뉴 화면의 헤더와 셀 내용을 중앙 정렬 |

## 동작 원칙

- 인라인 및 팝업 적용 결과는 기존 배치에 모으며 상단 변경 저장으로 서버에 반영한다.
- 코드명·설명 팝업은 locale만, 확장값 팝업은 extra1~5만 변경한다. 다른 편집 필드를 덮어쓰지 않는다.
- 팝업 취소는 해당 팝업의 임시 입력만 버린다. 이미 그리드에 반영된 다른 변경은 보존한다.
- READ만 있는 사용자는 내용 조회 팝업을 열 수 있으나 입력·적용할 수 없다. WRTE/DELT에 따른 기존 제어를 유지한다.
- 코드명은 하나 이상의 언어가 필요하며 기존 번역의 빈 값 삭제는 현행 API 계약에 따라 거부한다. 신규 선택 언어의 빈 값은 전송에서 제외한다.
- 인라인 편집 뒤 컬럼 정의를 다시 생성하지 않고 셀을 갱신하여 편집 포커스를 유지한다.
- 모바일은 그리드 가로 스크롤과 전체 화면 팝업을 사용한다. 언어·확장값 탭과 textarea 고정 높이 정책을 유지한다.

## 구현 위치

- static/vue/pages/BatchPage.vue: 컬럼, 분리 팝업, 신규 행 생성, 배치 저장 연결
- static/js/grid/CodeCellEditor.mjs: text/select/number 인라인 입력
- static/vue/components/Grid.vue: 공통 인라인 편집·셀 갱신
- static/vue/components/DialogHost.vue: 읽기 전용 팝업
- static/css/app.css, messages/admin-ui_*.properties: 정렬·스타일·다국어 문구

## 검증

신규/기존 행, 코드 잠금, 사용 여부·정렬순번, 팝업 분리·취소·필드 보존, 정렬순번 빈 값 차단, READ 전용, 중앙 정렬, 데스크톱·모바일 저장을 브라우저 fixture로 확인한다. Maven 및 JavaScript 계약 테스트도 실행한다.
