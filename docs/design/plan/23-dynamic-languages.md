# 공통코드 기반 동적 언어 목록

2026-09-20 · 구현 및 검증 완료

## 적용

- 공통코드 /SYS/LANG 활성 직계 하위 목록 API와 캐시 구분 추가.
- extra1 → 실제 로케일, name → 표시명, DB 정렬 → 컬럼/탭 순서.
- 관리 셸의 서버 초기 데이터와 Vue 공유 언어 목록을 동일한 기준으로 변경.
- 메시지 인라인 컬럼과 코드/메뉴 다국어 탭의 조회·새로고침 시 갱신.
- 비활성 언어 번역 보존, 빈 목록 안내 및 재조회 복구.
- 기존 고정 application.yml 언어 설정과 전용 속성 클래스 제거.

## 검증

- Java 전체 292개 통과: 활성 직계 하위 조회, 정확한 경로 계약 보존, enum 조합 오류, extra1 변환 포함.
- JavaScript 전체 55개 통과: 로케일 매핑, 요청 메뉴 ID/언어/취소 신호, 비활성 번역 보존 포함.
- 실제 Spring 렌더링 SFC와 정적 자산을 사용하는 Edge HTTP fixture에서 메시지 언어 컬럼 추가/제거, 새로고침, 코드·메뉴 언어 탭, 번역 보존을 확인.
- 390px 모바일 메뉴 팝업, 빈 언어 목록 안내 및 재시도 복구, 모든 언어 조회의 메뉴 컨텍스트를 확인.
- 현재 DB의 /SYS/LANG/KO_KR 및 /SYS/LANG/EN_US extra1이 ko_KR 및 en_US임을 읽기 전용으로 확인. 실제 언어 데이터를 변경하지 않았다.

결정: [ADR-0016](../adr/0016-common-code-language-source.md).

## 로그인 화면 추가 적용

- 로그인 Thymeleaf 컨트롤러에서 동일한 활성 언어 목록을 조회하여 언어 선택을 렌더링.
- 한국어/영어 고정 옵션 및 JavaScript의 두 언어 강제 선택을 제거. extra1의 정확한 값을 유지하며 로케일의 _/- 동등 표기를 선택 표시에 반영.
- 빈 목록에서는 언어 선택만 숨기며 로그인·비밀번호·중복 세션 처리와 plain HTML/CSS/vanilla JS 구조 유지.
- 추가 적용 검증: Java 전체 295개, JavaScript 55개 통과. 실제 Thymeleaf 렌더링을 사용하는 Edge fixture로 동적 언어 선택/전환, _/- 표기, 빈 목록 로그인, 390px 모바일 및 기존 비밀번호·중복 로그인 동작을 확인. 테스트용 언어는 mock 코드 서비스로 제공하여 실제 언어 데이터는 변경하지 않음.
