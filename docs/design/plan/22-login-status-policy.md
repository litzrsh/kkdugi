# 사용자·비밀번호 상태별 로그인 구현

2026-09-20 · 구현 및 검증 완료(이메일/휴면 해제 링크 TODO 제외)

## 적용

- 가입 대기/휴면/탈퇴/제재 로그인 차단 및 상태별 메시지.
- 정상 사용자의 초기 비밀번호 변경 강제, 만료 비밀번호 변경 또는 30일 연장.
- 기존 pwd_expr_dtm을 SessionUser.passwordExpiredAt으로 조회하며 실제 날짜 만료도 검사.
- 사용자 상태와 비밀번호를 서버에서 재확인하며 force=true로 우회 불가.
- 비밀번호 변경/연장·세션·최근 로그인 기록을 한 트랜잭션으로 처리. 중복 확인 시 롤백 후 동일 입력으로 재시도.
- 로그인 팝업의 한국어/영어, 모바일, 오류/재시도/취소, 메모리상의 비밀번호 정리.
- 사용자관리 상태 변경 안내와 현재 API 문서 갱신.

## 검증

- Java 전체 289개 통과. 정상/상태별 차단, 잘못된 비밀번호의 상태 정보 비노출, 초기 비밀번호 연장 거부,
  유효성 검사, 30일 만료일 갱신, 기존 변경 시각 보존, 실제 날짜 만료, 중복 세션 시 변경/연장 롤백 포함.
- JavaScript 전체 52개 통과. 로그인 form 규약 및 알려진 상태 코드 분기 포함.
- 실제 Thymeleaf 출력과 정적 자산을 사용하는 Edge HTTP fixture에서 변경/연장, 중복 확인 후 재시도,
  입력 불일치·서버 검증 실패, 취소/Esc 입력 삭제, 네트워크 실패, 모바일 레이아웃 확인.
- 데스크톱 초기 비밀번호 및 모바일 만료 팝업 스크린샷 확인. 실제 사용자 비밀번호를 브라우저에서 변경하지 않았다.
