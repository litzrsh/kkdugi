## 2026-09-16 화면 검토 반영

- 메시지 관리는 언어별 입력을 함께 표시하고, 공통코드·메뉴의 다국어 입력은 언어 탭으로 전환한다. 탭 이동 중 입력을 유지하며 방향키/Home/End 이동을 지원한다.
- 모든 textarea는 높이를 고정하고 사용자의 크기 조절을 막는다. 내용이 길면 내부 스크롤을 사용한다.
- 공통코드 확장 값 1~5는 각각 탭으로 구분한 textarea로 입력한다.
- 권한의 메뉴 연결은 계층 들여쓰기를 적용한 표로 표시한다. 조회/쓰기/실행(READ/WRITE/EXECUTE) 및 서버가 제공하는 추가 권한을 동일한 열에 배치한다. 실행 권한 키는 EXECUTE로 사용한다.
- 권한의 사용자 연결 및 사용자의 권한 연결은 항목명·시작일·종료일을 한 행에 표시한다. 미선택 행도 기간 입력을 표시하되 비활성화하며, 선택 시 활성화한다. 기존 기간 보존과 종료일 검증을 유지한다.
- 프로필 입력은 URL과 원형 이미지 미리보기를 함께 제공한다. 빈 URL/로딩 오류 시 기본 사용자 아이콘을 표시한다. field.type=profile로 입력 영역을 분리하여 향후 업로드 UI로 확장할 수 있다.
- 팝업 본문의 안내 아이콘 크기를 줄인다.
- GNB는 데스크톱·모바일에서 뷰포트 상단에 고정하고 본문에 헤더 높이만큼 공간을 확보한다.
- 배치 변경사항·저장 버튼은 화면 제목과 검색 영역 사이에 일반 흐름으로 배치한다. 하단 부유 영역을 제거한다.
- 모바일 매핑 표는 가로 스크롤로 열 정렬을 유지한다. 팝업 전체화면과 하단 저장 버튼을 유지한다.

검증: 계약 테스트 11개, Vue SFC 컴파일 및 5개 화면 렌더 검증 통과. 실제 브라우저에서 모바일 언어 탭 전환과 데스크톱 메뉴/사용자 매핑 표를 확인했다. 실제 API 연동은 별도 확인이 필요하다.

### 추가 검토: 메시지 인라인 편집 및 메뉴 권한 대상

- 메시지 등록은 그리드에 빈 행을 추가하고 코드 셀을 편집한다. 기존 코드의 식별자는 변경하지 않는다.
- 언어별 메시지는 팝업 대신 셀 내부 textarea로 편집한다. 셀 클릭으로 시작, Enter로 줄바꿈, Ctrl/Cmd+Enter 또는 포커스 이동으로 입력을 완료한다. 변경 저장으로 배치 반영한다.
- 메시지 행 수정 팝업 버튼을 제거한다. 신규 코드 형식과 현재 목록의 코드 중복을 저장 전에 검사한다. 다른 페이지와의 중복은 서버에서 검증한다.
- 프로그램 코드가 없거나 공백인 메뉴는 계층 구조만 표시한다. 선택 및 RBAC 체크박스를 표시하지 않고, 권한 상세/메뉴 연결 저장 데이터에서도 제외한다.
- 검증: 계약 테스트 11개 및 SFC 컴파일/렌더 검사 통과. 실제 브라우저에서 여러 줄 인라인 입력, 변경 건수, 신규 코드 입력, 프로그램 없는 메뉴의 체크박스 미노출 확인.

최종 수정: 메시지 인라인 편집은 여러 줄 textarea에서 한 줄 input[type=text]으로 변경했다. Enter로 입력을 완료하며 행 높이는 54px이다. 수정하지 않고 편집을 종료한 경우 기존 메시지 값을 그대로 보존한다. 위 여러 줄 편집 설명보다 이 규칙을 우선한다.
