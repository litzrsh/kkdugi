# 언어 변경 시 메뉴 갱신

## 구현

- 언어 변경 확인 후 현재 메뉴 해시를 유지하고 셸을 다시 로드한다. Spring 메시지와 Pragma 렌더링의 언어를 함께 맞춘다.
- 셸 초기화·메뉴 재시도 요청에 현재 locale을 lang 쿼리로 전달한다.
- 서버는 세션 메뉴 ID만 대상으로 번역을 새로 조회한다. 번역 누락은 세션 문구로 대체하고 메뉴 접근 범위·구조·권한은 유지한다.
- 편집 중 언어 변경을 취소하면 언어 선택 값과 현재 화면을 유지한다.

## 검증

- 실제 로그인 토큰으로 영어/한국어 재조회, 번역 변경 반영, 번역 누락, locale 쿠키, 트리 범위와 내부 필드 비노출을 확인한다.
- JS 계약 테스트로 lang 쿼리·인증 헤더·메뉴 컨텍스트·취소 signal을 확인한다.
- 브라우저에서 언어 변경 후 메뉴 재조회 및 현재 화면 유지, 편집 취소/확인 흐름을 검증한다.
