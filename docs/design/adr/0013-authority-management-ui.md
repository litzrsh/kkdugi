# ADR-0013: 권한관리의 행별 저장과 매핑 편집

- 상태: 채택
- 근거: docs/api/authority.md의 등록/저장/삭제 및 매핑 전체 교체 계약

## 결정

권한관리는 공통 배치 화면과 분리된 AuthorityPage를 사용하되 Grid와 DialogHost를 공유한다. 기본 정보, 메뉴 연결, 사용자 연결을 별도 팝업에서 저장하고 해당 팝업이 관리하지 않는 매핑은 요청에서 생략한다. 서버의 숫자 RBAC 코드를 사용하며 메뉴 트리는 접지 않고 같은 표 안에 표시한다.

변경된 API의 사용자 이름·프로필 이미지를 표시하고, 이름이 없으면 ID로 대체한다. SYS_ADMIN의 기존 사용자 매핑을 제거하면 복구 불가능할 수 있다는 API 계약에 따라 해당 행과 기간을 잠근다. 후보 검색은 선택된/기존 행을 보존하며, 검색만 했을 때 미저장 편집으로 취급하지 않는다.

## 결과

메뉴 컨텍스트와 서버 권한을 유지하면서 UI에서 실수로 다른 매핑을 초기화하는 것을 방지한다. 권한명/설명은 다국어 데이터 구조가 아니므로 임의의 언어 탭을 만들지 않는다. 화면 문구는 Spring message의 한국어/영어를 사용한다. 백엔드의 동시 편집 충돌 감지와 마지막 관리자 보호는 별도의 후속 작업이다.
