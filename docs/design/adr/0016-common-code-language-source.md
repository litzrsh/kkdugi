# ADR-0016: 사용 가능한 언어는 /SYS/LANG에서 조회

- 날짜: 2026-09-20
- 상태: 채택

## 배경

관리 UI가 application.yml의 고정 언어 목록을 사용하여 공통코드에서 추가하거나 비활성화한 언어가 메시지 컬럼과 다국어 탭에 반영되지 않았다.

## 결정

1. /SYS/LANG의 활성 직계 하위 코드를 유일한 언어 목록으로 사용한다. extra1은 실제 로케일 키이며, 코드명은 표시명이다. DB 정렬순서를 유지한다.
2. 기존 정확한 경로 및 enum 조회 계약을 유지하고 공통코드 API에 children=true를 추가한다. 부모와 자식 모두 활성인 항목만 반환한다.
3. 최초 Thymeleaf 렌더링과 Vue 화면 조회가 동일한 코드 서비스/조회 규칙을 사용한다. 고정 언어 설정은 제거한다.
4. Vue의 공유 언어 배열을 반응형으로 유지한다. 코드·메시지·메뉴 화면을 조회할 때 갱신하여 메시지 컬럼, 코드명/설명 탭, 메뉴 라벨/설명 탭 및 셸 언어 선택에 반영한다.
5. 로케일 누락/잘못된 값은 제외하고 중복 로케일은 첫 항목을 사용한다. 사용 가능한 언어가 없으면 안내하며 고정 언어로 대체하지 않는다.
6. 화면에서 제외된 언어의 기존 번역은 저장 시 보존한다. 열린 팝업은 진입 시 언어 목록을 유지하여 편집 도중 탭이 바뀌지 않게 한다.

## 범위와 결과

언어 목록은 화면 조회/새로고침/저장 후 재조회 시 갱신하며 실시간 서버 푸시는 사용하지 않는다. 관리자 코드 저장 시 기존 캐시 무효화를 사용한다. 데이터베이스 직접 수정은 캐시 무효화 또는 재시작이 필요하다. 로그인 페이지도 비인증 GET /login의 서버 렌더링에서 같은 AdminLanguageService를 사용한다. Vue나 공통코드 API의 비인증 공개 없이 option을 생성하고 extra1 값을 lang 파라미터로 전환한다. 현재 로케일을 선택 표시하며, 등록되지 않은 현재 로케일은 선택 불가 표시로 유지한다. 언어 목록이 비면 선택 UI만 숨기고 로그인 폼은 유지한다.
