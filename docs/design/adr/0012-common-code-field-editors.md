# ADR-0012: 공통코드 필드별 편집

- 날짜: 2026-09-19
- 상태: Accepted

## 결정

공통코드의 반복 입력 부담을 줄이기 위해 코드·사용 여부·정렬순번은 인라인 입력을 사용한다. 신규 등록도 빈 행 추가로 시작한다. 저장된 코드 값은 계층 경로와 연결되므로 사용자 확인에 따라 잠금을 유지한다.

코드명·설명과 확장값은 별도 행 버튼의 팝업으로 편집한다. 다국어는 언어별 탭, 확장값은 1~5 탭과 고정 높이 textarea를 사용한다. 팝업은 담당 필드만 반영하며 실제 서버 저장은 기존 배치 흐름을 따른다.

상태·작업 컬럼은 공통적으로 중앙 정렬한다. 읽기 전용 사용자도 팝업으로 값을 조회할 수 있고, 모바일은 기존 전체 화면 팝업을 유지한다.

구체적인 동작과 검증은 [작업 문서](../plan/18-common-code-inline-editing.md)를 참조한다.
