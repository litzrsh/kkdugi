# ADR-0015 로그인 상태 검사와 비밀번호 변경/연장

- 날짜: 2026-09-20
- 상태: 적용
- 근거: 사용자 요청의 사용자/비밀번호 상태 정의, 만료 연장 30일 확정

## 결정

로그인 필터가 자격 증명을 검증한 뒤 LoginPolicyService에서 사용자 상태 → 비밀번호 상태 → 중복 로그인 순으로 처리한다.
예약 상태 40/50도 로그인은 차단하되 탈퇴/제재 처리 자체는 추가하지 않는다. null 비밀번호 상태는 기존 데이터 호환을 유지한다.

로그인 URL 하나의 form 요청에 passwordAction(change/extend)와 newPassword를 추가한다.
새 인증 엔드포인트나 먼저 발급하는 세션은 없다. 사용자 행 잠금과 트랜잭션으로 상태 변경/비밀번호 초기화와의 경합을 검사한다.
중복 확인이 필요하면 비밀번호 변경/연장을 롤백하므로, 기존 자격 증명으로 확인 후 재시도할 수 있다.

변경/연장 유효 기간은 password-validity=30d로 설정한다. 연장은 해시와 마지막 변경 시각을 유지한다.
실제 변경은 현재 비밀번호 재사용을 금지하고 8자 이상/UTF-8 72바이트 이하를 서버·화면에서 검사한다(현재 BCrypt 인코더 한계 포함).

## 화면

plain HTML + CSS + vanilla JS를 유지한다. 초기 비밀번호는 변경/취소, 만료 비밀번호는 변경/연장/취소를 제공한다.
서버 상태 코드를 한국어/영어 UI 문구로 변환한다. 비밀번호를 URL·storage에 저장하지 않고 취소/Esc/이동 시 비운다.
휴면 계정은 이메일 해제 필요와 현재 서비스 준비 중을 안내한다. 이메일 발송 및 해제 링크 구현은 TODO이며 발송 성공으로 표시하지 않는다.

자세한 응답·오류·원자성 규약은 [인증 API](../../api/auth.md)를 따른다.
