# ADR 0008: 현재 JSON 로그인 API에 프런트 연결

- 날짜: 2026-09-17
- 상태: 현재 계약의 1차 연동 적용

## 결정

서버가 제공하는 JSON 로그인 + JWT Bearer + DB 세션 구조를 유지한다. 로그인 HTML은 Vue를 사용하지 않고 vanilla JS fetch로 기존 필터를 호출한다. API 변경 없이 중복 확인을 처리하기 위해 별도 페이지 대신 동일 문서의 확인 영역을 사용한다. 입력 비밀번호는 현재 문서 메모리에만 두고 취소/성공/페이지 이탈 시 비운다.

토큰은 탭 범위의 sessionStorage에 보관한다. 관리자 API는 매 요청 토큰을 읽어 Bearer 헤더를 전송한다. 쿠키 인증 체계를 새로 추가하지 않는다. 따라서 공개 HTML shell과 보호 API의 분리를 전제로 하며, 아직 permitAll인 서버의 경로별 인가 구현은 필수 후속 작업이다. XSS로 접근 가능한 토큰이라는 특성 때문에 임의 HTML 실행을 피하고 운영 CSP를 별도로 검토해야 한다.

ADR 0007의 challenge/form POST는 목표 흐름이며 현재 서버 구현과 같지 않다. 이번 결정은 정상/중복 로그인 연결만 구체화한다. 최초/만료 비밀번호 변경 강제는 서버 계약을 받은 뒤 연결한다. 클라이언트만으로 필수 변경을 강제했다고 간주하지 않는다.

연동 및 검증 내역: [로그인 백엔드 연결](../plan/09-login-backend-integration.md).
